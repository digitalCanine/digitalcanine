### Imaginary Ecosystem

[imaginary linux](https://github.com/digitalCanine/imaginary-linux): a git-based, security-focused arch distro. no iso. boot plain arch, clone the repo, read the scripts, install. the point is a secure system you don't have to babysit. my daily driver runs on it. it's in hyfetch now, somehow.

[imaginary-angel](https://github.com/digitalCanine/imaginary-angel): the system guardian. modular bash, watches the system, auto-fix off by default because you should know what it's touching.

### Firefox extensions

[better new tab](https://addons.mozilla.org/en-CA/firefox/addon/dc-better-new-tab/): a firefox extension that makes the new tab... prettier, i guess.

[universal colorscheme](https://addons.mozilla.org/en-CA/firefox/addon/dc-universal-colorscheme/): changes the colorscheme of every website according to the colors you set. firefox again
